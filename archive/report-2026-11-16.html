01

核心结论

五条判断，按重要性排序。每条都附可核验的数字，口径见第 02 节。

01

月度榜单已被 Agent 生态吞没，几乎没有非 AI 项目

月榜 14 个项目中 13 个与 AI / Agent 直接相关，合计新增 254,845 星，占榜单月增星总量的 93.3%。唯一的非 AI 项目是 2018 年创建的 OSINT 工具 sherlock-project/sherlock：月增 18,371，其中 10,412（57%）发生在最近 7 天。榜单不再是「技术趋势全景」，而是「Agent 生态施工进度表」。

254,845 / 273,216 = 93.3%
02

「反 AI 味」从吐槽变成了一个可购买的品类

hallmark、impeccable、taste-skill、unslop 四个项目一个月共 91,376 星，解决的是同一个问题：AI 生成的界面千篇一律——居中大标题、渐变卡片、空洞文案。它们的方法论也高度一致：先给参考图与艺术指导，再用 critique / audit 类命令自查，最后用浏览器截图闭环。设计评审流程被编码成了 agent 可执行的命令。

91,376 stars / 4 projects / 1 thesis
03

Skill 正在取代库和应用，成为新的分发包形态

月榜里 8 个项目是 skill / plugin，而不是传统意义的库或应用：security-audit-skill、hallmark、impeccable、taste-skill、claude-seo、video-shotcraft、knowledge-work-plugins、anthropics/skills。分发方式是「GitHub 仓库 + 一行安装」，获得了 npm 时代的传播效率；代价是没有版本约束、没有权限声明，安装即把文件读写与命令执行权限交给一段陌生人的提示词。

8 / 14 是 skill 或 plugin
04

冷启动速度刷新纪录：一个月 5.8 万星，864 个新仓库破 300 星

过去 30 天新建的仓库中，有 864 个已突破 300 星；榜首 Gathin23/cleanyourtv 在 10 月 17 日创建，一个月拿到 58,273 星。前 10 名合计 216,415 星。放在同一份数据里对照更直观：2018 年创建的 sherlock 用 8 年积累 112,469 星，而 cleanyourtv 用 30 天就拿到了它八年总量的一半——「热门」的绝对量级已经通胀到需要重新校准的程度（见第 08 节）。

864 repos > 300★ / 30 days
05

第二大情绪出口是「设备主权」：去广告、解锁算力、跨设备玩游戏

Android TV 去膨胀与 tvOS 风格桌面（cleanyourtv 58,273 + aerial-tv 12,017）、国产安卓去广告（8,128）、iOS 地区码魔改（7,737）合计 86,155 星；把 Switch 游戏搬到 Mac / iPhone 的项目合计 31,860 星；解锁 GeForce 20/30/40 系 FP16 算力的 gpu-unlock 19,718 星。共同点是「把厂商拿走的东西拿回来」，传播极快，法律风险也最高。

06

六条主线

把两个月榜共 39 个项目按「解决什么问题」重新切分，比按语言或榜单名次切分更有信息量。

主线 A · 能力分发

Skill 变成新的 npm 包

月榜 8/14 是 skill 或 plugin。它们不是代码库，而是「行为规范 + 工具脚本」的组合，通过一个仓库、一行命令完成安装。传播效率极高，但缺少 semver、缺少权限声明、缺少依赖锁定。

代表：cloudflare/security-audit-skill（43,540）、anthropics/skills（195,346 总星）。

8 个项目月增 157,523 · 占月榜总量 57.7% · 官方仓库总星 195,346
主线 B · 审美工程

反 AI 味：把设计评审写成命令

四个项目共享同一套方法论：艺术指导 → 参考图 → 生成 → critique 自查 → 浏览器截图复检。hallmark 直接把自己定义成「anti-AI-slop」，unslop 的定位则是把 vibecoded、一眼 AI 的界面改造成真正设计过的界面。

值得注意的是，这是需求侧信号而非技术突破：用户已经能一眼认出 AI 做的页面，并愿意为此安装工具。

四项目合计 91,376 stars · 最快冷启动 16,751 / 18 天

瓶颈已经从「会不会想」转向「能不能操作真实世界」。浏览器自动化（agent-browser）、视频渲染（hyperframes）、跨会话记忆（claude-mem）、手机远程接管（t3code）分别对应执行、产出、留存、接入四个环节。

pingdotgg/t3code 月增 33,583，是这条线上增长最快的项目。

08

噪音与风险

这一节是给「准备真的装一个」的人写的。star 通胀已经是结构性问题，需要别的信号来校正。

Star 通胀01 / METRIC

月榜前 5 名平均 30,616 星/月，榜首 43,540。同一份数据内部对照：cleanyourtv 30 天 58,273 星，sherlock 8 年 112,469 星；本月 864 个新建仓库已突破 300 星。当「一个月上万星」变成常态，star 的区分度就会被稀释。结论：star 更能反映传播效率，而不是使用深度。

星 / 关注比02 / RATIO

健康项目的 star/watcher 比通常在 20–80。本月异常值：pingdotgg/t3code 305、Nutlope/hallmark 245、video-shotcraft 209、security-audit-skill 171。对照组：anthropics/skills 12、sherlock 12。

比值越高，说明「点收藏」与「持续关注」的落差越大——多数人只是路过。这个指标不能证明刷星，但能提示你：先看 issue 响应速度和 commit 频率，再决定要不要装。

Fork / Star 异常03 / SIGNAL

正常项目的 fork 数约为 star 的 10%–20%。本月有两个项目达到 79%：ZhuLinsen/daily_stock_analysis（57,568 / 72,497）与 Minireel/HGhub（7,125 / 8,990）。

合理推测是「一键部署式 fork」（部署即复制仓库），也可能包含非自然传播。无论原因，这类项目的 fork 数不能当作采用度。

权限与供应链04 / SECURITY

skill 的本质是「让 agent 按陌生人的指令执行命令」。它通常需要文件读写、shell 执行、网络访问，而绝大多数 skill 仓库没有权限声明、没有签名、没有版本锁定。安装一个 skill，等价于把开发机的部分控制权交给一个未经审计的 prompt 包。

建议：在容器或独立用户下运行；安装前读一遍 SKILL.md 与所有脚本；固定 commit hash 而不是跟随 main。

许可证陷阱05 / LICENSE

heydamir/unslop 使用 CC-BY-4.0——这是内容许可，不适合软件代码，商用前需确认授权范围。三个项目为 NOASSERTION（无法自动识别）：Gathin23/cleanyourtv、Minireel/HGhub、xiaoyang111222/cn-math-taxonomy，意味着默认保留所有权利，企业内部使用前必须人工确认。
